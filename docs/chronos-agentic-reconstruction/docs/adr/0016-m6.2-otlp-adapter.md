# ADR-0016 — M6.2 OTLP adapter ingesta local

**Status:** Accepted
**Date:** 2026-09-21
**Cycle:** M6 / M6.2 (adapter OTLP de ingesta local)
**chronos HEAD:** `e219e1ff` (post M6.1 alignment).
**Spike location:** off-repo, `/home/rubentxu/.jcode/scratch/m6.2-otlp-adapter/`.

## 1. Context

ROADMAP §M6 §86 lists M6.2 as "adapter OTLP de ingesta local".
The requirement is: **the bridge between an external W3C trace
context arriving as an HTTP header and the chronos internal
correlation system**. Specifically:

- HTTP request comes in with `traceparent` (and optionally
  `tracestate`) headers per W3C Trace Context.
- The adapter **translates** the headers into a typed
  `ExternalTraceContext` (the type from M6.1).
- The adapter **binds** an internal `InvocationId` to that
  context, producing a `RecordedInvocation`.
- The result is exposed so downstream chronos-core code can
  use it (in this spike: returned in the HTTP response body).

This ADR delivers the **adapter contract** — what the HTTP
transport must produce for chronos to consume. It is
deliberately a pure-stdlib spike: no actix, no hyper, no
tokio, no reqwest. Why: zero deps + maximum portability, and
the test of M6.2 is the **adapter contract**, not the HTTP
stack. A production version can graduate to a real HTTP stack
without changing the contract.

## 2. Decision

**Accepted.** The adapter is a single function:

```rust
pub fn adapter(headers: &Headers) -> IngestOutcome;
```

That returns one of four outcomes:

| Outcome | Status | When |
|---|---|---|
| `Recorded(RecordedInvocation)` | 200 | traceparent present + valid → bind invocation + external context |
| `InternalOnly(RecordedInvocation)` | 200 | no traceparent → use `root()`, internal-only |
| `BadTraceparent { raw, error }` | 400 | traceparent malformed → preserve raw for forensics |
| `BadTracestate { raw, error }` | 400 | traceparent OK but tracestate malformed |

Every malformed input **carries the original raw value and the
specific error variant** — no silent defaults, no lossy
fallback to "root". This is the No-Silent-Lies contract.

### 2.1 Headers extraction

The adapter reads HTTP headers via a minimal `Headers` parser:

```rust
pub struct Headers { pub entries: Vec<(String, String)> }
```

`Headers::get("traceparent")` returns `Option<&str>`. Keys
are normalised to lowercase (HTTP/1.1 is case-insensitive per
RFC 7230 §3.2). Whitespace trimmed. No case folding is done
on values (HTTP allows quoted-string folding but it's not
used here).

### 2.2 Boundary translation

The `adapter()` function calls `ingest_traceparent()`:

```rust
pub fn ingest_traceparent(
    raw_traceparent: Option<&str>,
    raw_tracestate: Option<&str>,
) -> Result<ExternalTraceContext, IngestError>;
```

This delegates to the M6.1 parsers `parse_traceparent` and
`parse_tracestate`. **Any failure surfaces as a typed error**.
The adapter then:

1. On `Ok(etc)` where `etc.is_root()` → `InternalOnly`.
2. On `Ok(etc)` where `etc.is_root() == false` → `Recorded`.
3. On `Err(Traceparent{..})` → `BadTraceparent`.
4. On `Err(Tracestate{..})` → `BadTracestate`.

### 2.3 Invocation binding

`adapter()` always generates a fresh `InvocationId::new()`
(UUID v4). The `InvocationId` is bound to the
`ExternalTraceContext` via the M6.1 bridge:
- `Recorded` outcome → `invocation.record_external(&etc)`.
- `InternalOnly` outcome → `RecordedInvocation::internal_only(invocation)`.

The two contracts remain **separated at the type level**, only
joined through the explicit bridge (`RecordedInvocation`).

## 3. HTTP wire format

### 3.1 Request

```
GET /ingest HTTP/1.1\r\n
Host: localhost\r\n
traceparent: 00-{trace-id 32hex}-{parent-id 16hex}-{flags 2hex}\r\n
tracestate: vendor1=value1,vendor2=value2\r\n
Connection: close\r\n
\r\n
```

Either header is optional; the adapter handles:
- Both present + valid → `Recorded`.
- Only `traceparent` present + valid → `Recorded` (no tracestate).
- Only `tracestate` present → `InternalOnly` (tracestate ignored if no traceparent).
- Neither → `InternalOnly`.
- `traceparent` malformed → `BadTraceparent`.
- `tracestate` malformed (only when `traceparent` is OK) → `BadTracestate`.

### 3.2 Response

**200 OK** (Recorded or InternalOnly):
```
HTTP/1.1 200 OK\r\n
Content-Type: text/plain\r\n
Content-Length: {N}\r\n
Connection: close\r\n
\r\n
recorded
{invocation_id}|{traceparent}|{tracestate}\n
```

The 3-segment format is exactly the M6.1 `RecordedInvocation::to_recorded()` output.
For `InternalOnly`, the traceparent and tracestate segments are
empty.

**400 Bad Request** (BadTraceparent or BadTracestate):
```
HTTP/1.1 400 Bad Request\r\n
Content-Type: text/plain\r\n
Content-Length: {N}\r\n
Connection: close\r\n
\r\n
bad-traceparent
raw: {original raw value}\n
error: {specific parse error}\n
```

The raw value is preserved **byte-exact** so the caller can
debug what they sent. The error is the human-readable form of
the M6.1 parse error.

## 4. Behavioural spec

### 4.1 Headers parsing

- `Headers::get("traceparent")` is case-insensitive.
- Whitespace around values is trimmed.
- `Headers::parse_block` accepts HTTP-header-block with `\r\n`
  separators (the format the stdlib TCP listener produces).
- Headers without `:` are silently skipped (defensive: a
  malformed header line should not break the whole request).

### 4.2 Outcome determination

| Input | Outcome |
|---|---|
| Empty headers | `InternalOnly` |
| `traceparent` valid, no `tracestate` | `Recorded` (tracestate=None) |
| `traceparent` valid + `tracestate` valid | `Recorded` (tracestate attached) |
| `traceparent` valid + `tracestate` malformed | `BadTracestate` |
| `traceparent` malformed | `BadTraceparent` |
| `traceparent` all-zero | `BadTraceparent` (W3C §3.2.2.3) |
| `parent-id` all-zero | `BadTraceparent` |

### 4.3 No silent defaults

- `parse_traceparent` failure: raw value + error preserved.
- `parse_tracestate` failure: raw value + error preserved.
- No fallback to "root" on bad input.
- `is_root()` only true when caller deliberately sent empty.
- HTTP status reflects the truth: 200 only on success, 400 on
  parse failure.

### 4.4 HTTP server semantics

- Single-threaded `TcpListener` on `127.0.0.1:{port}`.
- One request per connection (Connection: close).
- Reads request line + headers until empty line.
- Does not read body (this spike doesn't need it; M6.3 will
  add body parsing).
- Writes response + closes connection.

## 5. Spike runnable

The spike has TWO binaries:

- `m6_2_otlp_adapter_server` — HTTP server on port (default
  4819).
- `m6_2_otlp_adapter_client` — CLI client that sends a
  request with optional `traceparent` + `tracestate` and
  prints the response.

The library has **zero external dependencies** (path dep on
M6.1 only). No `tokio`, no `hyper`, no `actix`. Pure stdlib
HTTP for maximum portability.

## 6. Why this matters for M6

M6.2 closes the **HTTP transport layer** for OTel contexts:

- **M6.3 (correlation)** binds the adapter output to chronos
  internal events. The `RecordedInvocation` returned by the
  adapter is what M6.3 attaches event IDs to.
- **M6.4 (exporter)** emits the `RecordedInvocation`
  downstream. The `traceparent` is preserved byte-exact so
  the exporter can carry it through.
- **M6.5 (security/redaction)** applies to the body of
  events, not to the `RecordedInvocation` itself (which is
  pure identifiers and IDs).
- **M6.6 (UAT)** spins two services with cross-service calls
  — the adapter ingests the `traceparent` from one service
  and the exporter emits to a collector; M6.2's adapter is
  the entry point.
- **M6.7 (gates)** test that the round-trip
  `adapter → record → export` preserves the trace context.

## 7. Out-of-scope / future work

- **No real HTTP stack** (actix/hyper/tokio). The spike uses
  stdlib TCP for portability. A production version should
  graduate to a real HTTP stack while preserving the
  `adapter()` contract.
- **No TLS / authentication**. The spike is plain HTTP on
  loopback.
- **No request body parsing**. M6.3 will add this for
  propagating events through the same HTTP channel.
- **No HTTP keep-alive**. Single-request-per-connection only.
- **No vendor-tag policy**. W3C tracestate is parsed
  permissively; vendor validation belongs to
  `CapTracestatePolicy` follow-up.
- **No multi-port or service-discovery**. The spike is a
  single-port listener.
- **No `SpanId` mutation**. The adapter treats incoming
  `parent-id` as opaque; it doesn't compute child span IDs.
  Child-span synthesis belongs to M6.4 (exporter).

## 10. Closing note

**M6 §M6.2 is delivered.** The HTTP adapter ingests
`traceparent` + `tracestate`, translates them to typed
`ExternalTraceContext`, binds an `InvocationId`, and returns
a `RecordedInvocation`. All failures are typed and preserve
the raw input for forensics.

The spike is **stdlib-only** (path dep on M6.1) and can be
lifted into chronos-core as a submodule when the M6 chapter
begins productisation. The adapter contract — `adapter(headers)
→ IngestOutcome` — is what M6.3, M6.4, M6.6, and M6.7 will
all consume.
