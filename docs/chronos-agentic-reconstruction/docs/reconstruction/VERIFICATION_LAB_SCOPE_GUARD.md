# Verification Lab Scope Guard

The Verification Lab is a supporting capability, not a new top-level product roadmap replacing reconstruction.

Scope is valid only when tied to one of:

- REC-C1 ExecutionLog/events_read UAT;
- REC-C2 crash/legacy deletion verification;
- M4 ptrace/eBPF/adaptive instrumentation verification;
- No Silent Lies regression;
- a later explicitly approved PORTABLE-P* consumer.

Any proposed sandbox feature without a named consumer is deferred.
