# Verification Lab Glossary

- **Observer**: Chronos instance observing another Chronos subject/runtime.
- **Subject**: Chronos instance or external project being observed.
- **Execution Environment**: backend providing controlled execution and declared capabilities.
- **PROCESS**: lightweight process/filesystem isolation class.
- **SYSTEM**: reproducible userspace/container class.
- **KERNEL**: VM/kernel-controlled execution class.
- **Evidence Bundle**: portable result/provenance/artifact package emitted by a scenario.
- **Portable Execution Runtime**: future optional execution plane for external projects/cross-OS hosts.
