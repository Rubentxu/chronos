# Portable Runtime — Current Non-Goals

Until PORTABLE-P0 is explicitly activated, do not build:

- a remote worker scheduler;
- cloud execution infrastructure;
- multi-tenant sandboxing;
- generic developer workspaces;
- a cross-platform installer solely for the future runtime;
- Kubernetes control plane integration;
- Firecracker orchestration;
- distributed artifact infrastructure beyond what current Chronos milestones require.

The Verification Lab must first prove the underlying execution/evidence seams with Chronos itself.
