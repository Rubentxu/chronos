## Correction (post-close): the vault defect is a contract violation

I previously wrote that the vault identity scheme was "a design decision needing
the operator". **That was wrong.** The SDDK `knowledge-graph` protocol already
specifies the scheme, so this is conformance work, not a free design choice.

The protocol mandates `CYC-{date}-{slug}.md` for cycles, `INC-NNN-{slug}.md` in
`incs/`, `TERM-{Slug}.md`, `ADR-NNN-{slug}.md`, and requires every node to carry
`type`, `title`, `slug`, `status`, `created`, `stale_after`.

Measured against that:

| Mandated | Present |
|---|---|
| `CYC-*` cycle nodes | **0** |
| `INC-*` nodes | **0** (`incs/` does not exist; the vault has an empty `incidences/`) |
| `TERM-*` nodes | **0** |
| `ADR-NNN-{slug}.md` | 8 files named `000N-slug.md`, **two of them numbered `0002`** |
| `REQ-{Slug}.md` | 26, conforming |
| `$VAULT/templates/` | **absent**, so the protocol's "read the template first" rule is unsatisfiable |

This explains v014 having no vault node: **no cycle in this project is a vault
node at all.** The 60 validate errors are a symptom of a vault that was
hand-built without the protocol, not 60 independent mistakes.

`sddk adopt apply --root . --scope .` was run to try the sanctioned convergence
path. It returned `status: complete` and changed nothing: file count stayed at
163, `templates/` and `incs/` are still absent, errors still 60. The vault is
**byte-identical** to the backup taken before the attempt (`diff -rq` clean).
Adoption is a no-op when the receipt already matches, so it cannot repair this.

Renaming the 30 colliding files would clear the errors and still leave a vault
with no cycle nodes, no incidence nodes and no templates. The protocol's real
path is `knowledge scan` → review → `import` → `verify`, which builds a
hash-addressed registered vault instead of patching a hand-built one.

The decision is still operator-scoped, but for a different and more accurate
reason than first stated:

- **(a)** migrate the vault onto the governed protocol, or
- **(b)** accept it as a non-conforming legacy artifact and amend the
  `vault-index-current` gate contract so cycles can archive without a clean vault.

Either way v014 stays `RELEASED/phase=archive` until then. Its release is done;
only the archive transition is outstanding. The v0.1.4 tag is untouched at
`98c4cd23`.
